# Neural Networks From Scratch

I use AI every day, and at some point I decided that wasn't enough. I wanted to understand how it actually works.

This repo is my learning journey: building neural networks step by step, from the ground up, instead of just using tools I don't understand.

## How it started

I began by experimenting with NumPy on my own, without much structure. It taught me a lot, but I wasn't being serious about it yet. Then I picked up a book that walks through the topic properly, and I committed to doing this right.

The book builds everything with **PyTorch**, so that's what this repo uses from here on. My early NumPy experiments are still in the `numPy` folder as a record of where I started.

## Why I'm doing this

- I learn best by building things myself
- I want strong fundamentals, not copied snippets
- I'm genuinely excited about this field and want to get really good at it

## What to expect

This is a work in progress. Some of it will be messy, and some of it will be wrong before it's right. I'm sharing it anyway, because learning in public keeps me honest and consistent.

If you're on a similar path, or you've been there already, I'd love to hear from you.
